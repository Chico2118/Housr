# Housr

A scalable full-stack real-estate marketplace platform designed to simplify property discovery, seller verification, inquiry management, and buyer-seller communication through a seamless and modern digital experience.

---

## Overview

Housr enables users to explore properties, connect with verified sellers, manage inquiries, and communicate in real time through an integrated messaging system. The platform focuses on performance, scalability, secure authentication, and responsive user experience.

---

## Key Features

- Secure JWT-based authentication and authorization
- Property listing creation and management
- Seller verification workflow
- Real-time buyer-seller chat using Socket.IO
- Wishlist functionality for saved properties
- Cloudinary integration for property image management
- Inquiry management system
- Responsive and optimized user interface
- RESTful API architecture

## Problem Statement

Property discovery platforms often lack centralized communication systems, secure seller verification, and streamlined inquiry management. Housr addresses these challenges by providing an integrated platform for managing listings, interactions, and communication efficiently.
